# 双轴事务助理 Web 产品设计简报

> 文档状态：用户名 + 密码、开放自助注册、同账号跨设备共享、首期不做自助密码找回、永久删除任务均已确认；语音流程见 [ADR 0004](./adr-0004-local-voice.md)，阶段 6 参数见 [ADR 0005](./adr-0005-speech-stage-6.md)。

## 1. 产品方向

帮助用户记录、组织和查询学习与生活事务，使用重要度与紧急度两个独立维度管理事务。首期提供账号登录、任务管理、对话式事务助理和可查看的对话历史。前端保留经典 5×5 舒尔特表；取消眼动追踪与眼动反馈，后端本期不提供训练 API 或保存训练数据。

用户以用户名和密码登录。服务端负责保存账号下的任务、必要偏好和对话记录；前端不发送可任意指定的 user_id，后端从已验证的登录会话确定数据归属。LLM 密钥只在服务端环境变量或部署 Secret 中配置。

## 2. 主要用户流程

1. 访问者注册用户名与密码，或登录已有账号。
2. 登录后查看该账号的事务列表；新账号从空的服务端事务数据开始。
3. 用户可以手动创建、查询、修改、完成和删除任务。
4. 用户可以创建多个对话、查看旧对话并继续；删除对话不会删除任务。
5. Agent 结合当前对话上下文和必要的任务查询结果回答问题。自然语言提出的任务写入先显示变更提案，用户确认后执行。
6. 前端录音并本地转写，用户可编辑文字；后端校准和核验文字，用户明确发送后才创建对话消息和 Agent Run。原始音频默认不上传。
7. 前端提供经典 5×5 舒尔特表；不使用摄像头或眼动反馈，不向本期后端发送训练数据。

## 4. 数据归属、保存与删除

账号是用户数据的归属边界。请求不接受客户端指定 user_id；每个任务、对话、消息、提案和运行记录都必须归属于已认证账号，并在每次读取或修改时校验归属。

| 数据 | 保存位置与生命周期 |
|---|---|
| 用户名、密码验证材料 | 服务端 PostgreSQL；只保存自助注册所需的密码安全哈希，不保存明文密码 |
| 登录会话 | 服务端会话表；浏览器只持有 HttpOnly 会话 Cookie |
| 任务 | 服务端 PostgreSQL，按账号隔离；提供单条删除 API 与界面操作 |
| 明确偏好 | 服务端按账号保存；只收集产品确实需要的设置 |
| 对话与消息 | 服务端按账号保存，直到用户手动删除该对话 |
| 当前对话摘要/Agent run | 仅辅助续接同一对话；不跨对话复用。删除对话时连同关联记录清理 |
| 原始录音 | 默认仅在前端处理、不上传；用户主动触发的可选回退只在后端内存中处理，结束后释放，不作为历史对话保存 |
| 服务日志 | 仅保留请求 ID、端点、状态、耗时及用量等运行元数据；不写入密码、会话凭证、任务正文或完整对话正文 |
| 旧前端演示数据 | 服务端初始为空；不自动导入 xihack 的 localStorage 演示数据 |
| 训练记录 | 首期不生成 |

手动删除任务和对话都需要前端操作入口及后端 API。对话删除会清理其消息、摘要、未完成提案和可清理的运行数据，不连带删除任务。任务永久删除且不可恢复；所有任务创建、修改、完成和删除都先保存待确认意图，再由确认入口执行。用户目前不要求“一键删除账号全部数据”功能。

同一账号登录不同设备时共享该账号的任务、偏好和对话。首期不提供自助密码找回；用户忘记密码后无法自行恢复账号，产品不提供密码重置入口。

## 5. Agent 与交互原则

- 查询任务时直接展示真实任务数据；查不到时明确说明。
- 任务目标不明确时追问或列出候选，不猜测并写入。
- 自然语言创建、修改、完成、删除先生成提案；用户确认后由后端执行。
- 页面中的完成勾选也先生成待确认意图，确认后执行；不提供依赖软删除的撤销语义。
- Agent Tool 不接收 user_id；账号范围由认证中间件和应用服务注入。
- 新建对话从空对话历史开始；用户任务作为业务状态存在，可由 Agent 在新对话中按需查询。
- 对话内容是用户可见的历史，不等于跨对话记忆。模型只收到当前对话所需上下文及必要任务查询结果。
- LLM 错误或无效输出不能造成任务写入；失败时保留已保存的用户消息并返回可恢复状态。

## 6. 用户年龄与边界

首发面向 18 岁以上用户，注册时要求明确声明已满 18 岁；暂不收集出生日期。产品不做医疗或心理诊断，不声称提高一般注意力能力。身份参数见 [ADR 0002](./adr-0002-identity.md)。

## 7. 初步验收场景

- 新用户可以注册、登录、退出；登录后只能访问自己账号的数据。
- 未登录的客户端不能访问任务、对话和 Agent API。
- 用户在任一设备创建的任务和对话，在同账号的其他设备登录后可查看和继续。
- 新注册账号的服务端任务列表为空；不会导入旧 localStorage 样例。
- 用户可新建多个对话、查看旧对话、在旧对话续聊，并手动删除对话。
- 删除对话不删除任务；任务可独立删除。
- Agent 查询结果来自当前账号真实任务；自然语言写操作必须先确认。
- 账号、密码和会话信息不会出现在前端存储、通用日志或模型提示中。
- 前端经典 5×5 舒尔特表按真实点击计时；眼动反馈不出现，也不向后端生成训练记录。
- 如果首期提供语音，用户能编辑本地转写结果；校准不会自动发送消息或创建 Agent Run。任务写入仍必须经提案和明确确认。
